# Okonomi from Scratch

## Dependencies

- JDK 21 - required to run Gradle
- Android CLI - pulls the Android SDK 37 and required tools
- Ruby - if using fastlane instead of Gradle

## Build

Using [mise](https://mise.jdx.dev/) is recommended (but not required) because it will pull all the necessary dependencies for you.

```bash
mise install && mise run prep
```

The apps are built with [fastlane](./fastlane/Fastfile) which uses Gradle underneath. Run lanes with `bundle exec <lane>`:

| Lane | Builds |
|---|---|
| `android build` | builds the debug APK, and reports where it landed |
| `android build type:release` | the same for release APK|
| `android install` | builds the debug APK and installs it, `serial:` picks the device |
| `android install type:release` | the same for the release APK |
| `android uninstall` | removes whichever build is installed, `serial:` picks the device |
| `ios build` | builds the app for the simulator |
| `ios build type:release` | builds the app for the simulator, in the Release configuration |

If you don't want to pull in mise and all the dependencies it lists into your environment, you can build with Gradle directly after you have OpenJDK and Android SDK setup:

- Android Debug: `./gradlew :androidApp:assembleDebug`.
- Android Release: `./gradlew :androidApp:assembleRelease`.
- iOS app: open the [/iosApp](./iosApp) directory in Xcode and run it from there.

## Data sources

The app bundles a SQLite dictionary generated by `:tools:dictgen` from source files in git-ignored `data/`. The first build will automatically download the archives below into `data/archives/` and decompresses them into `data/` before generating.

| Archive in `data/archives/` | Downloaded from | Extracted to | Provides |
|---|---|---|---|
| `JMdict_e.xml.gz` | `https://www.edrdg.org/pub/Nihongo/JMdict_e.gz` | `JMdict_e.xml` | Dictionary entries |
| `JMnedict.xml.gz` | `https://www.edrdg.org/pub/Nihongo/JMnedict.xml.gz` | `JMnedict.xml` | Proper names |
| `kanjidic2.xml.gz` | `https://www.edrdg.org/kanjidic/kanjidic2.xml.gz` | `kanjidic2.xml` | Kanji readings and meanings |
| `radkfile.gz` | `https://www.edrdg.org/pub/Nihongo/radkfile.gz` | `radkfile` | Radical decomposition |
| `jpn_sentences.tsv.bz2` | `https://downloads.tatoeba.org/exports/per_language/jpn/jpn_sentences.tsv.bz2` | `jpn_sentences.tsv` | Japanese example sentences |
| `eng_sentences.tsv.bz2` | `https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences.tsv.bz2` | `eng_sentences.tsv` | Their English translations |
| `jpn_indices.tar.bz2` | `https://downloads.tatoeba.org/exports/jpn_indices.tar.bz2` | `jpn_indices.csv` | Word index linking sentences to entries |
| `kanjivg.zip` | `https://github.com/KanjiVG/kanjivg/releases/download/r20260714/kanjivg-20260714-all.zip` | `kanji/` | Per-stroke outlines for the stroke-order diagrams |


## Tests

The checks are also driven with [fastlane](./fastlane/Fastfile), which groups the Gradle tasks underneath. Run lanes with `bundle exec <lane>`:

| Lane | Runs |
|---|---|
| `test` | the same set as the PR checks, in one Gradle build |
| `unit_tests` | the dictionary generator's tests, and the shared tests on the JVM |
| `migrations` | replays the user database's migrations against the checked-in schema snapshots |
| `compile` | compiles both targets, `commonTest` for Kotlin/Native included |
| `lint` | AGP lint over the debug variant |
| `ios_tests` | the shared tests on an iOS simulator, so macOS only |
