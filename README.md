# okonomi

Modern Japanese–English dictionary mobile app for language learners.

This is a Kotlin Multiplatform project targeting Android, iOS.

* [/iosApp](./iosApp/iosApp) contains an iOS application. Even if you’re sharing your UI with Compose Multiplatform,
  you need this entry point for your iOS app. This is also where you should add SwiftUI code for your project.

* [/shared](./shared/src) is for code that will be shared across your Compose Multiplatform applications.
  It contains several subfolders:
  - [commonMain](./shared/src/commonMain/kotlin) is for code that’s common for all targets.
  - Other folders are for Kotlin code that will be compiled for only the platform indicated in the folder name.
    For example, if you want to use Apple’s CoreCrypto for the iOS part of your Kotlin app,
    the [iosMain](./shared/src/iosMain/kotlin) folder would be the right place for such calls.

### Running the apps

Use the run configurations provided by the run widget in your IDE's toolbar. You can also use these commands and options:

- Android app: `./gradlew :androidApp:assembleDebug`.
- iOS app: open the [/iosApp](./iosApp) directory in Xcode and run it from there.
- After changing dependencies: `./gradlew :shared:exportLibraryDefinitions` regenerates the library list shown in Settings (`shared/src/commonMain/composeResources/files/aboutlibraries.json`).

### Dictionary sources

The app bundles a SQLite dictionary generated by `:tools:dictgen` from source files in `data/` (git-ignored, about 420 MB uncompressed). The build fails with the missing file names if any are absent. Download and decompress each into `data/`, keeping the names below:

| File in `data/` | Downloaded from | Provides |
|---|---|---|
| `JMdict_e.xml` | `http://ftp.edrdg.org/pub/Nihongo/JMdict_e.gz` | Dictionary entries |
| `JMnedict.xml` | `http://ftp.edrdg.org/pub/Nihongo/JMnedict.xml.gz` | Proper names |
| `kanjidic2.xml` | `http://www.edrdg.org/kanjidic/kanjidic2.xml.gz` | Kanji readings and meanings |
| `radkfile` | `http://ftp.edrdg.org/pub/Nihongo/radkfile.gz` (EUC-JP) | Radical decomposition |
| `jpn_sentences.tsv` | `https://downloads.tatoeba.org/exports/per_language/jpn/jpn_sentences.tsv.bz2` | Japanese example sentences |
| `eng_sentences.tsv` | `https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences.tsv.bz2` | Their English translations |
| `jpn_indices.csv` | `https://downloads.tatoeba.org/exports/jpn_indices.tar.bz2` (a tar) | Word index linking sentences to entries |
| `kanjivg/` | `https://github.com/KanjiVG/kanjivg/releases/download/r20260714/kanjivg-20260714-all.zip` | Per-stroke outlines for the stroke-order diagrams |


Regenerate with `./gradlew :tools:dictgen:run`. The app build does it automatically and reports the resulting size and per-table counts.

### Running tests

Use the run button in your IDE's editor gutter, or run tests using Gradle tasks:

- Android tests: `./gradlew :shared:testAndroidHostTest`
- iOS tests: `./gradlew :shared:iosSimulatorArm64Test`
